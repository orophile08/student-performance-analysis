# 📊 Student Performance Analysis

A data analysis project that explores various factors affecting student academic performance using **Python, Pandas, NumPy, and Matplotlib**.

The project analyzes a dataset of **200 students** and investigates relationships between study habits, attendance, previous academic performance, assignments, CGPA, and final scores.

---

## 🎯 Project Objective

The objective of this project is to analyze student performance data and identify patterns and relationships between different academic factors.

The analysis focuses on:

- Student age distribution
- Branch-wise student distribution
- Study hours
- Attendance
- Previous scores
- Assignment scores
- CGPA
- Final scores
- Relationships between academic variables

---

## 📁 Dataset

The dataset contains information about **200 students** with the following features:

| Column | Description |
|--------|-------------|
| Student_name | Name of the student |
| Student_ID | Unique student identification number |
| Age | Age of the student |
| Branch | Engineering branch of the student |
| Study_Hours | Number of study hours |
| Attendance | Student attendance percentage |
| Previous_Score | Previous academic score |
| Assignments_Score | Assignment performance score |
| CGPA | Cumulative Grade Point Average |
| Final_Score | Final academic score |
